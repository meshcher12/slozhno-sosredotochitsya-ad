# Сложно сосредоточиться

Адаптивная страница о внимании и концентрации. Тему можно выбрать вручную или оставить автоматический режим, который следует настройкам системы.

Чтобы открыть проект локально, откройте `index.html` в браузере.

[Репозиторий проекта на GitHub](https://github.com/meshcher12/slozhno-sosredotochitsya-ad)
